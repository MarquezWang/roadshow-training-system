## A. 项目新建流程

- [ ] 打开 `/projects/new` 页面正常，无运行时错误。
- [ ] 上传 PDF 文件后，材料上传和解析状态正常。
- [ ] 上传 PPT 或 PPTX 文件后，材料上传和解析状态正常。
- [ ] 材料解析完成后，可以手动点击开始识别。
- [ ] AI 项目档案识别完成后，项目名称、一句话简介、所属领域、应用场景、技术关键词、产品形态正常填入。
- [ ] TRL 成熟度判断完成后，TRL 字段正常填入或提示手动选择。
- [ ] 用户手动修改过的字段不会被后续 AI 识别结果覆盖。
- [ ] 合作需求与转化对接字段校验正常。
- [ ] 点击“完成建档并进入项目”后按钮进入提交中状态，不能重复点击创建多个项目。
- [ ] 项目创建成功后进入项目详情页。
- [ ] 创建失败时恢复可操作状态，并显示友好错误提示。
